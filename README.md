# 归程

归程是一个帮助直系亲属或授权办理人整理身后事的数字陪同工具。它通过三步问卷生成城市化的五步办理路径，提供材料与进度勾选、高德附近殡仪馆搜索，以及 Kimi 个性化填充与机构证据核验。

## 本地运行

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
# 在 .env 中配置 AMAP_API_KEY 和 KIMI_API_KEY
.venv/bin/uvicorn server:app --host 127.0.0.1 --port 8000
```

打开 `http://127.0.0.1:8000`。

首次启动会在 `data/guicheng.db` 创建本地 SQLite 数据库。注册、登录、会话、办理进度、求助和回应都保存在该数据库；密码仅保存 PBKDF2 加盐哈希。

## 内容与 AI 分工

1. 北京、上海、广州、深圳的政策与公共电话由 `content.py` 中的城市资料包预置，并直接链接政府 reference，不调用 Kimi 临时检索。
2. 问卷完成后，Kimi 在固定的五节点视觉模板中填写城市、离世地点、费用需求和用户补充情况对应的行动、材料、地点、费用口径与提醒。
3. 未录入的城市只显示全国公共渠道，并明确提示当地资料待录入，不生成猜测政策。
4. 第 3 节点的附近机构仍单独使用高德计算距离，并用可打开的政府页面核验证据。

## 机构推荐原则

1. 高德只提供 POI、坐标、距离与地图电话。
2. 浏览器 GPS 会先转换为高德坐标，并反查所在城市，避免坐标偏移或城市政策错配。
3. Kimi 官方 `web-search` 工具并行检索机构资质、收费与减免条件。
4. 程序会打开引用来源（含政府价目表 PDF），只有正文相近位置同时出现机构名称和金额时，才展示该价格。
5. 没有至少两家同口径可比总价时，不声称“最便宜”；先推荐距离最近且政府来源已核对的机构。
6. Kimi 超时或失败时保留高德距离候选，不显示未核实价格。

## 隐私边界

- API 密钥仅保存在服务端 `.env`，不会发送到浏览器。
- 精确位置、AI 核验结果和用户补充内容不写入浏览器长期存储。
- 用户补充内容会在生成个性化 SOP 时发送给 Kimi，但会先移除明显的电话和邮箱；精确定位只用于附近机构查找。
